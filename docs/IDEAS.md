# 未来演进灵感备忘（Ideas）

> 本文档整理自日常随想记录（原 `docs/note.txt`），收录暂不急于在主干落地的远期想法，待核心闭环跑通后择机立 Issue 评估。

1. **服务端 API 模式与 Harness 模式分离**
   - 当无法调用本地工具（或工具环境不可用）时，仍能优雅降级为纯对话回复，不阻塞基础沟通。
2. **引入 Cloudflare Tunnel 解放公网 IP 限制**
   - 借助 Cloudflare 隧道穿透内网，让家里的电脑开机即可充当个人服务器，降低云主机依赖与成本。
3. **精简 App，将功能模块化为插件**
   - 保持客户端外壳极简，把各类能力尽量沉淀为可插拔的后端/前端插件。
4. **浏览器与交互设施选型备忘**
   - 调研 `ego` / `playwright` 等浏览器或自动化交互方案（待进一步核对 `ego` 的具体适用场景）。
